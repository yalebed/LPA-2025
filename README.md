## Реализованные возможности
### Типы данных: 
1. строковый (str)
2. символьный (symb)
3. целочисленный 1 байт (byte)
4. целочисленный 4 байта (int)
5. логический (torf)

### Арифметические операции:
сложение (+), вычитание (-), умножение (*), деление (/)

### Унарные операции:
инкремент (++), декремент(--), инверсия (~)

### Побитовые операции:
побитовое ИЛИ (|), побитовое И (&)

### Литералы:
целочисленные (десятичные и двоичные)

### Функции стандартной библиотеки:
преобразование строки в число, сравнение двух строк


### Условные операторы:
условный оператор с выбором из множества значений
условный оператор с выбором из двух значений
